Common questions
Frequently asked questions

Which game engine do you use?

We primarily work with Unity and Unreal Engine 5, and also build with Godot for lightweight or open-source projects. The choice depends on your platform targets, visual fidelity requirements, and budget. We'll recommend the best fit during scoping.

How long does a game project take?

A hyper-casual mobile game can be delivered in 6–10 weeks. A mid-core mobile or PC game typically runs 4–9 months. VR/AR experiences and enterprise simulations are scoped case by case, usually 2–6 months. You'll receive a detailed milestone timeline in your project proposal.

Can you build a multiplayer game?

Yes. We have experience building real-time and turn-based multiplayer games using Photon, Mirror Networking, and custom socket-based backends. We handle matchmaking, lobby systems, anti-cheat, and scalable server architecture.

What VR headsets do you develop for?

We build for Meta Quest 2/3/Pro (standalone), SteamVR (PC VR including Valve Index and HTC Vive), PlayStation VR2, and WebXR for browser-based VR. We can target multiple headsets from a single codebase where possible.

Do you handle app store submission?

Yes. We manage the full submission process for Google Play, Apple App Store, Steam, Epic Games Store, and console platforms (PlayStation, Xbox, Nintendo). This includes compliance checks, metadata, screenshots, and age ratings.

Can you work with our existing game or add features to it?

Absolutely. We take on co-development, feature additions, platform ports, and game rescue projects. We'll start with a codebase audit to understand the existing architecture before scoping any changes.

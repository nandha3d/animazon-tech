### Featured Case Study: Nanobot Blood-Brain Barrier Animation

**Problem**
A biotech research team needed to visualize how engineered nanobots navigate through the bloodstream and breach the blood-brain barrier to deliver targeted drug payloads. Existing diagrams and static illustrations failed to convey the dynamic, microscale nature of the process. The animation was needed for a conference keynote and investor presentation.

**Solution**
Animazon developed a scientifically grounded animation pipeline that combined biological accuracy with cinematic production values. We worked directly with the research team's published papers and anatomical references to ensure every visual element reflected the correct biology — from the morphology of the endothelial cells to the behavior of the nanobot delivery mechanism.

**Technology & Process**
- Software: Blender (animation & rendering), Cinema 4D (motion graphics), After Effects (post-production)
- Scientific review: cross-referenced with peer-reviewed literature on BBB permeability and nanoparticle behavior
- Pipeline: concept sketch → storyboard → 3D model → scene layout → animation → lighting & rendering → compositing → final delivery
- Total runtime: 3 minutes 22 seconds
- Render time: 48+ hours across 4K resolution frames

**Result**
The animation was used as the centrepiece of the team's conference keynote and later embedded in their investor pitch deck. The client reported strong positive feedback from both scientific peers and non-specialist investors — noting that the animation made the science accessible to a general audience without sacrificing accuracy.

## 13. Design System

### Visual Identity

**Overall Aesthetic:**
Dark, cinematic, and premium. Animazon's visual identity communicates sophistication and technical mastery. The design should feel closer to a high-end film studio than a typical digital agency.

### Color Palette

| Role | Color | Hex |
|---|---|---|
| Background | Deep Black | `#0A0A0F` |
| Surface | Dark Navy | `#0F1020` |
| Primary Accent | Electric Blue | `#2563EB` |
| Secondary Accent | Deep Purple | `#7C3AED` |
| Highlight | Neon Blue | `#38BDF8` |
| Text Primary | Off White | `#F8FAFC` |
| Text Secondary | Cool Gray | `#94A3B8` |
| Border | Subtle Gray | `#1E293B` |

### Typography

| Use | Font | Weight | Size Range |
|---|---|---|---|
| Primary Headings | Montserrat or Poppins | 700–800 | 48px–96px |
| Sub-headings | Poppins | 600 | 24px–40px |
| Body Text | Inter | 400–500 | 16px–18px |
| UI Labels | Inter | 500–600 | 12px–14px |
| Code / Technical | JetBrains Mono | 400 | 14px–16px |

### Component Principles

- **Cards:** Dark surface background, subtle border, soft glow on hover
- **Buttons:** Primary — Electric Blue fill; Secondary — Ghost/outline style
- **Sections:** Generous whitespace, clear visual hierarchy, purposeful use of accent color
- **Imagery:** All images should be dark-toned, high contrast, and cinematic in feel
- **Animations:** Smooth, purposeful micro-interactions — no gratuitous movement

```
  (Depth of proof, quality demonstration)
          ↓

          ↓
```

## 15. Advanced Features

> **These features differentiate Animazon from standard agency websites and create memorable, functional experiences.**

### 1. Interactive 3D Viewer
Embed an interactive 3D model viewer (using Three.js or Sketchfab) on the Portfolio or Home page. Allow visitors to rotate, zoom, and explore a sample 3D model directly in the browser — demonstrating capability and creating an engaging proof-of-concept moment.

### 2. Animation Player / Showreel
A dedicated, full-screen animation player that showcases the best work in a curated showreel. Custom controls, category filtering, and seamless autoplay create a premium viewing experience.

### 3. AI Chat Assistant
An AI-powered chat widget that helps visitors describe their project and get an instant, relevant response. The assistant can:
- Qualify the lead by asking about project type, budget, and timeline
- Point visitors to relevant case studies and service pages
- Capture contact details and brief descriptions for follow-up
- Answer common questions about services, process, and pricing

### 4. Project Cost Estimator
An interactive pricing calculator that helps prospects self-qualify and understand investment levels before they reach out. Inputs might include:
- Service type
- Animation duration or page count
- Complexity level
- Deadline urgency
- Deliverable formats

Output: An estimated price range, a recommended package, and a CTA to get a formal quote.

### Module Architecture

The project uses **nwidart/laravel-modules** for a clean, feature-based code organization. Each major website section is its own self-contained module:

```
Modules/
├── LandingPage/          ← Home page, hero, features, testimonials
├── Portfolio/            ← Filterable gallery, project cards
├── CaseStudies/          ← Detailed case study pages
├── Blog/                 ← SEO articles, content management
├── Services/             ← Service-specific pages (Medical, Product, Web, App)
├── Industries/           ← Industry-targeted landing pages
├── Contact/              ← Contact form, enquiry handling
└── Resources/            ← Lead magnet downloads, gated content
```

Each module contains its own: `Controllers`, `Models`, `Routes`, `Views`, `Migrations`, `Providers`.

### Frontend Asset Pipeline

Assets are compiled via **Vite** with the `laravel-vite-plugin`. Tailwind CSS is configured to scan all Blade views for class names.

```javascript
// vite.config.js
import { defineConfig } from 'vite';

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
    ],
});
```

```javascript
module.exports = {
```
